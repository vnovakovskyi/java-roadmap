# The Streams API

> [!info] Topic
> **Area:** Modern Java · **Module:** 5 · **Priority:** must · **Est:** 5h
> **Why this matters:** Streams express data transformations — filter, map, reduce, group — clearly
> and without manual loops. Modern Java codebases use them everywhere; this is a must-have skill.

## Learning Objectives
- Build stream pipelines: source → intermediate ops → terminal op.
- Use `filter`, `map`, `sorted`, `collect`, `reduce`.
- Group and summarize data with `Collectors`.

## Concepts
- [ ] A pipeline: `stream()` → intermediate (`filter`, `map`, `sorted`, `distinct`, `limit`) →
      terminal (`toList`, `collect`, `forEach`, `count`, `reduce`, `findFirst`).
- [ ] Streams are **lazy** (nothing runs until a terminal operation) and **don't mutate** the
      source. A stream can be consumed only once.
- [ ] `.toList()` *(Java 16+)* returns an unmodifiable list; `collect(Collectors.groupingBy(...))`,
      `Collectors.counting()`, `Collectors.joining(", ")` are the workhorses.
- [ ] `reduce` folds elements into one value; `mapToInt(...).sum()` / `.average()` for numbers.
- [ ] Keep lambdas in a pipeline free of side effects; a plain loop is fine when it's clearer.
- [ ] Pairs naturally with `Optional` (`findFirst`, `max`) and method references.

## Practice
**Goal:** Rewrite loops as stream pipelines.
**Steps:**
- [ ] From a `List<Person>`: collect the names of everyone over 18, sorted.
- [ ] Group people by city with `groupingBy`; count per group.
- [ ] Sum ages with `mapToInt(...).sum()`; compute the average.
- [ ] Find the oldest person with `max(Comparator.comparing(Person::age))` and handle the empty
      case.

## Self-check
Answer out loud or on paper first, then expand to compare.

> [!question]- What's the difference between intermediate and terminal operations?
> Intermediate operations (`filter`, `map`, `sorted`) return a new stream and are lazy. A terminal
> operation (`toList`, `count`, `forEach`) runs the pipeline and produces a result.

> [!question]- Why does `list.stream().filter(p -> p.age() > 18);` on its own do nothing?
> Streams are lazy: without a terminal operation, the pipeline never executes.

> [!question]- Can you reuse a stream after a terminal operation?
> No — it throws `IllegalStateException`. Create a new stream from the source.

> [!question]- `stream.toList()` vs `collect(Collectors.toList())`?
> `toList()` (Java 16+) returns an unmodifiable list. The collector's list happens to be mutable
> today but makes no guarantee; prefer `toList()` unless you need to modify the result.

> [!question]- How would you count people per city?
> `people.stream().collect(Collectors.groupingBy(Person::city, Collectors.counting()))` → a
> `Map<String, Long>`.
