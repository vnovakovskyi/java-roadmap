# Spring Boot Intro and Project Setup

> [!info] Topic
> **Area:** Spring · **Module:** 9 · **Priority:** must · **Est:** 3h
> **Why this matters:** Spring Boot is the dominant Java web framework and the single most in-demand
> skill for junior Java jobs. Getting a project running is the gateway to everything else here.

> [!warning] Reading older tutorials
> Most Spring material online was written for Spring Boot 2 or 3. This roadmap uses **Spring Boot 4**.
> Differences you'll meet: `spring-boot-starter-webmvc` (was `-web`), `@MockitoBean` (was `@MockBean`),
> Jackson 3 (`tools.jackson.*` packages), Spring Security 7's lambda-only configuration, and
> `jakarta.*` instead of `javax.*` (since Boot 3). When in doubt, check the
> [Spring Boot 4.0 Migration Guide](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.0-Migration-Guide).

## Learning Objectives
- Generate and run a Spring Boot project.
- Understand starters, auto-configuration, and the project layout.
- Know what the embedded server and main class do.

## Learn
- [ ] Use [start.spring.io](https://start.spring.io) to generate a project: Spring Boot 4.x, Java
      25, Maven; dependencies Spring Web, Spring Data JPA, PostgreSQL Driver, Validation.
- [ ] Do: the
      [Spring "Building a RESTful Web Service" guide](https://spring.io/guides/gs/rest-service/).
- [ ] Read:
      [Spring Boot — Auto-configuration](https://docs.spring.io/spring-boot/reference/using/auto-configuration.html).

## Concepts
- [ ] Spring Boot = the Spring Framework + sensible defaults + an embedded server; you run a normal
      `main` and it boots a web app on port 8080.
- [ ] **Starters** (`spring-boot-starter-webmvc`, `-data-jpa`, `-validation`) pull in curated
      dependency sets; the Boot BOM manages all versions.
- [ ] **Auto-configuration** wires beans based on what's on the classpath and in your properties —
      and backs off when you define your own.
- [ ] `@SpringBootApplication` = `@Configuration` + `@EnableAutoConfiguration` + `@ComponentScan`
      (of its package and sub-packages).
- [ ] Layout: the main class, `application.properties`/`.yml` in `src/main/resources`, tests in
      `src/test/java`. Build and run with `./mvnw spring-boot:run`
      ([[M6.03 - Tooling - Maven (Project, Dependencies, Lifecycle)]]).

## Practice
**Goal:** Boot a running app.
**Steps:**
- [ ] Generate a project and run it; confirm the server starts on port 8080.
- [ ] Add a trivial `/hello` endpoint and call it from the browser and `curl`.
- [ ] Change the port with `server.port` in `application.properties`.
- [ ] Run with `--debug` and skim the auto-configuration report: what was configured and why?

## Self-check
Answer out loud or on paper first, then expand to compare.

> [!question]- What is a Spring Boot starter?
> A dependency that bundles everything needed for one capability (web, JPA, security) with
> compatible versions, so you add one line instead of many.

> [!question]- How does auto-configuration decide what to set up?
> Through conditions: which classes are on the classpath, which properties are set, and which beans
> you've already defined — your own beans win.

> [!question]- Which three annotations does `@SpringBootApplication` combine?
> `@Configuration`, `@EnableAutoConfiguration`, and `@ComponentScan`.
